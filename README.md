# Станция испытания аккумуляторных ячеек

Консольное приложение на C# .NET 8.0 для симуляции работы научно-производственной лаборатории по тестированию аккумуляторных ячеек.

## Техническое задание

Приложение разработано согласно техническому заданию по системному программированию. Требуется демонстрация корректного использования:

1. **ThreadPool** - обработка ячеек в пуле потоков
2. **SemaphoreSlim** - ограничение количества одновременно заряжающихся ячеек
3. **Mutex** - защита единственного калибровочного стенда
4. **CancellationToken** - поддержка аварийной остановки

## Архитектура приложения

### Модель данных
- `BatteryCell` - модель аккумуляторной ячейки
- `CellStatus` - перечисление статусов ячейки
- `CellResult` - результат обработки ячейки
- `StationConfiguration` - конфигурация станции
- `ProcessingStatistics` - итоговая статистика обработки

### Основные классы
- `BatteryTestStation` - основной класс станции, управляющий обработкой
- `Program` - точка входа с обработкой командной строки и Ctrl+C

## Требования к системе

- .NET 8.0 SDK
- Операционная система: Windows, Linux, macOS

## Использование

### Компиляция и запуск
```bash
dotnet build
dotnet run -- [опции]
```

### Опции командной строки
```
-b, --batch <число>       Количество ячеек в партии (по умолчанию: 20)
-s, --slots <число>       Количество слотов зарядки (по умолчанию: 4)
-d, --diagnostics <число> Диагностических итераций на ячейку (по умолчанию: 100000)
-t, --timeout <мс>        Автоматическая отмена через указанное время в мс
-h, --help                Показать эту справку
```

### Примеры использования
```bash
# Штатное завершение (20 ячеек, 4 слота зарядки)
dotnet run

# Тестирование с меньшей нагрузкой
dotnet run -- -b 5 -s 2 -d 10000

# Автоматическая отмена через 3 секунды
dotnet run -- -b 30 -s 3 -t 3000

# Большая партия с ограниченными ресурсами
dotnet run -- --batch 40 --slots 6 --timeout 5000
```

## Особенности реализации

### ThreadPool
- Используется `ThreadPool.QueueUserWorkItem` для постановки задач
- Каждая ячейка обрабатывается как отдельный рабочий элемент
- Перехват необработанных исключений внутри рабочего элемента
- Вывод состояния пула потоков до и после обработки

### SemaphoreSlim
- Ограничивает количество одновременно заряжающихся ячеек
- Ожидание семафора с учётом CancellationToken
- Гарантированное освобождение семафора в блоке finally
- Обработка прерывания ожидания при отмене

### Mutex
- Защищает единственный калибровочный стенд
- Используется `WaitHandle.WaitAny` для ожидания мьютекса или отмены
- Гарантированное освобождение мьютекса при исключении или отмене
- Освобождение мьютекса только из того же потока

### CancellationToken
- Поддержка аварийной остановки по Ctrl+C
- Опциональная автоматическая отмена по таймауту
- Периодическая проверка отмены во время длительных операций
- Корректное освобождение ресурсов при отмене

### Потокобезопасность
- ConcurrentDictionary для хранения результатов
- Interlocked для потокобезопасных счетчиков
- Блокировка вывода в консоль
- Синхронизация доступа к общим ресурсам

### Журналирование
- Временные метки для всех событий
- Идентификаторы потоков и ячеек
- Подробное описание состояния ресурсов
- Журнал всех этапов обработки

## Критерии приемки

1. Приложение компилируется и запускается на .NET 8.0
2. Все ячейки обрабатываются в пуле потоков
3. Количество одновременно заряжающихся ячеек не превышает заданное число слотов
4. Калибровка выполняется только одной ячейкой в любой момент времени
5. Отмена по Ctrl+C или по таймауту приводит к корректной остановке
6. После отмены приложение не зависает
7. Все занятые SemaphoreSlim и Mutex освобождаются
8. Итоговая сумма статусов равна количеству ячеек
9. Повторный запуск приложения работает без ошибок блокировки ресурсов
